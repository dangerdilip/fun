SECTION 1 — PROJECT IDENTITY
════════════════════════════════════════════════════════════════════════════════

WORKING TITLE       : FRACTURE
                      (Final name shortlist: Fracture / Sovereign / Ironbound)

TAGLINE             : "Every fighter has a pattern. Find it. Break it."

CONCEPT             : A 1v1 browser-based 3D fighting game where two players
                      move freely in a bounded arena and fight using light,
                      medium, heavy and combo attacks fuelled by a mana system.
                      Select characters carry Rage Arts activated near death.
                      Movement is fully 3D — walk, dash, jump, double jump,
                      crouch. Combat is weighty, deliberate and impactful.

CORE PILLARS        :
    1. Fluid 3D Freedom      — Move anywhere in the arena in real time
    2. Weighty Combat        — Every hit has visible impact and meaning
    3. Mana & Rage           — Resource strategy adds depth beyond button mashing
    4. Character Depth       — 4 unique fighters, each with distinct identity
    5. Friends-First         — Two friends connect via room code, no installs

TARGET AUDIENCE     : Students, casual competitive players, friend groups

PLAYERS             : 2 online (Multiplayer) or 1 vs AI (Single Player)

COST TO PLAY        : Free — link opens in browser, no account needed

COST TO BUILD/HOST  : ₹0 — 100% free stack, no subscriptions ever

────────────────────────────────────────────────────────────────────────────────
2.1 CORE ENGINE & RENDERING
────────────────────────────────────────────────────────────────────────────────

TOOL         : Three.js
WEBSITE      : https://threejs.org
COST         : Free — open source (MIT licence)
WHY          : The gold standard for 3D in the browser. No installation needed
               on your laptop — runs entirely as JavaScript in any browser.
               Handles 3D scenes, cameras, lighting, model loading, animations.
               Used by major companies worldwide. Enormous documentation and
               community support. Perfect for a 3D fighting game.
HOW TO USE   : Include via CDN link in HTML — no npm, no build tools needed.
               <script src="https://cdn.jsdelivr.net/npm/three@latest/build/three.min.js">
ALTERNATIVE  : Babylon.js (https://babylonjs.com) — also free, slightly more
               engine-like, good fallback if Three.js proves complex.

────────────────────────────────────────────────────────────────────────────────
2.2 PHYSICS & HITBOX DETECTION
────────────────────────────────────────────────────────────────────────────────

TOOL         : Rapier.js
WEBSITE      : https://rapier.rs
COST         : Free — open source (Apache 2.0 licence)
WHY          : Lightweight, blazing fast physics engine that runs in the browser
               via WebAssembly. Handles capsule-based character hitboxes,
               collision detection, ground checks, and physics interactions.
               No performance hit even on low-end laptops.
HOW TO USE   : Load via CDN. Claude Code will write all physics integration.

ALTERNATIVE  : Cannon-es (https://github.com/pmndrs/cannon-es) — also free,
               pure JavaScript physics, slightly simpler but less accurate.

2.5 MULTIPLAYER / REAL-TIME CONNECTION
────────────────────────────────────────────────────────────────────────────────

PRIMARY      : Partykit.io
WEBSITE      : https://partykit.io
COST         : Free tier — more than sufficient for 2-player friend games
WHY          : Purpose-built for real-time multiplayer browser games.
               Handles room creation, room codes, syncing player inputs,
               WebSocket connections. Simple API. Works with plain JavaScript.
HOW IT WORKS : Player A creates room → gets 6-character code
               Player B enters code → connected
               Game syncs inputs between both browsers in real time

ALTERNATIVE  : Socket.io on Railway.app
WEBSITE      : https://railway.app
COST         : Free tier (500 hours/month — enough for playing with friends)
WHY          : More control, slightly more setup. Railway hosts your
               Socket.io server free. Good fallback option.

ALTERNATIVE  : PeerJS
WEBSITE      : https://peerjs.com
COST         : Free — open source
WHY          : Direct peer-to-peer browser connection. No server needed.
               Simplest option if Partykit proves complex.

SECTION 6 — COMBAT SYSTEM (Complete Rules)
════════════════════════════════════════════════════════════════════════════════

────────────────────────────────────────────────────────────────────────────────
6.1 MOVEMENT
────────────────────────────────────────────────────────────────────────────────

CONTROL         : W/A/S/D keys (keyboard) or left stick (gamepad if supported)
DIRECTION       : Relative to camera — fully 3D movement in any direction

    W / Up        → Move forward (toward opponent or into arena)
    S / Down      → Move backward
    A / Left      → Strafe left
    D / Right     → Strafe right

WALKING SPEED   : 5 metres per second
DASH            : Double-tap W = dash forward (12 m/s burst, 0.3s duration)
                  Double-tap S = dash backward (identical)
                  Cannot attack during first 0.3 seconds of dash
JUMP            : Spacebar — 2.5m height, directional influence from WASD
DOUBLE JUMP     : Spacebar again mid-air — adds 1.8m additional height
CROUCH          : Hold Ctrl — lowers hitbox by 40%, avoids all high attacks
                  Can move slowly while crouching

────────────────────────────────────────────────────────────────────────────────
6.2 ATTACK BUTTONS
────────────────────────────────────────────────────────────────────────────────

    U = Light Attack  (fast, safe, chainable)
    I = Medium Attack (staggers or launches, combo starter)
    O = Heavy Attack  (slow, high damage, wall/ground interaction)
    J = Combo String  (preset sequence, beginner-friendly)
    K = Special Move  (mana-consuming — full or half depending on hold)

────────────────────────────────────────────────────────────────────────────────
6.3 MANA SYSTEM
────────────────────────────────────────────────────────────────────────────────

STARTING VALUE  : 0% at beginning of every round
GAIN ON HIT     : +10% per successful hit landed
GAIN ON DAMAGE  : +5% per hit received (fighting back fuels you)
MAXIMUM         : 100%
DISPLAY         : Semi-transparent bar below health bar

SPENDING:
    Full Special (K)       = Costs 100% mana
    Half Special (K hold)  = Costs 50% mana (where applicable)
    Rage Art               = Costs ALL remaining mana (any amount)

MANA DOES NOT carry over between rounds. Resets to 0 each round.

────────────────────────────────────────────────────────────────────────────────
6.4 HEALTH SYSTEM
────────────────────────────────────────────────────────────────────────────────

STARTING HP     : 100% per round
ROUND WIN       : Opponent reaches 0% HP, OR timer runs out (higher HP wins)
MATCH           : Best of 3 rounds
ROUND TIMER     : 75 seconds per round
HP DISPLAY      : Bar at top of screen. Drains from outside in toward centre.

────────────────────────────────────────────────────────────────────────────────
6.5 BLOCKING & DEFENSE
────────────────────────────────────────────────────────────────────────────────

BLOCK HIGH/MID  : Hold direction away from opponent while they attack
BLOCK LOW       : Crouch + hold direction away from opponent
DAMAGE REDUCTION: 90% when blocking correctly
CHIP DAMAGE     : 10% damage still applies even on perfect block

GUARD METER     : Small bar below health. Not visible until it starts depleting.
                  Heavy attacks deplete it significantly.
                  When guard meter empties → GUARD BREAK
                  Guard break = opponent staggers for 1.5 seconds (punish window)

────────────────────────────────────────────────────────────────────────────────
6.6 WALL INTERACTIONS
────────────────────────────────────────────────────────────────────────────────

WALL SPLAT      : Hitting opponent into boundary wall causes wall splat.
                  Opponent is pinned briefly (0.8 seconds extra stun).
                  Follow-up attacks are easier to land.
                  Visual: crack appears in wall at impact point.

WALL BOUNCE     : Heavy attack into a wall-splatted opponent causes wall bounce.
                  Opponent flies back toward centre of arena.
                  Attacker has time to run in and continue combo.

────────────────────────────────────────────────────────────────────────────────
6.7 COMBO SYSTEM
────────────────────────────────────────────────────────────────────────────────

JUGGLING        : Medium attack that causes launch → air combo possible
                  Air combo sequence: Light, Light, Combo String
                  Gravity increases on each air hit (diminishing returns)

GROUND BOUNCES  : Heavy attacks can bounce opponent off floor for follow-ups

WALL BOUNCE     : (See 6.6 above)

COMBO DAMAGE SCALING : Each hit in a long combo deals slightly less damage
                       than previous (prevents infinite loop combos)

────────────────────────────────────────────────────────────────────────────────
6.8 SPECIAL MOVE CINEMATICS
────────────────────────────────────────────────────────────────────────────────

When a Special Move (full mana cost) is activated:
    — Camera shifts to dramatic preset cinematic angle
    — UI elements dim to 20% opacity
    — Motion blur applies to attacker during animation
    — Slow motion effect on impact frame (0.3 seconds)
    — Camera snaps back to gameplay immediately after
    — Entire sequence adds approximately 2-3 seconds total

When a Rage Art is activated:
    — Same as above but more dramatic camera angle
    — Screen briefly darkens at edges (vignette)
    — Character's theme music sting plays
    — Longer slow motion on final hit

                  browser every frame via WebSocket. Applied locally.
                  Simple and effective for a low-latency friends game.

INPUT DELAY     : 2 frames offline, variable (up to 6 frames) based on ping.
                  Acceptable for casual friends play.

DISCONNECTION   : If opponent disconnects mid-match, game pauses and shows
                  "Opponent Disconnected" with option to return to menu.

AFTER MATCH     : Both players see:  [ REMATCH ]  [ BACK TO LOBBY ]
